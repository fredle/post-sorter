# Post Sorter

Photograph a letter or bill and get what you need to do, by when, with a reminder.

An iPhone app generated by app-factory. The spec is in `SPEC.md`.

## Stack (fixed - do not change)

- SwiftUI, Swift 5 language mode, iOS 17.0+, iPhone only, portrait.
- The Xcode project is generated by XcodeGen from `ios/project.yml`. There is
  no `.xcodeproj` and no `Info.plist` in git: add Info.plist keys (usage
  descriptions, `UIBackgroundModes`, ...) under `info.properties` in
  `project.yml`, never in a generated file.
- Sources live in `ios/App/`; every `.swift` file there is compiled.
- `.github/workflows/ios.yml` compiles on a GitHub macOS runner and uploads to
  TestFlight with Apple's cloud signing. There is no Mac and no Swift compiler
  on the machine that builds this app, so CI is the first compile.

## Factory-owned - leave as-is

- `.github/workflows/ios.yml`.
- In `ios/project.yml`: the `settings`, bundle ID, team, version and device
  family. Add Info.plist keys, frameworks or a new target only if the spec
  needs them.
- `ios/App/Assets.xcassets/AppIcon.appiconset/`.

## Rules for building the app

- Write code that compiles first time: no compiler is available here. Use
  only APIs available on iOS 17, mark UI types `@MainActor` where Swift 6
  concurrency checking would otherwise complain, and avoid APIs you are unsure of.
- No third-party Swift packages unless the spec cannot be done without one.
- Store state with SwiftData, `@AppStorage` or files in the app's container.
- Every permission prompt needs its usage-description key in `project.yml`.
- No analytics, no tracking, no accounts unless the spec says so.
- Keep logic in plain structs and functions, separate from views.
- If `server/` exists, the app's backend is there. Read `server/README.md`.
  The app reads the server's origin from the `BackendURL` Info.plist key.
